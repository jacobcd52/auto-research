## 2. Follow-ups that already exist (so proposals do not duplicate them)

- **"Subagents comply more"** (LW nfXAPJqytuHKrRNpT). 13 workplace worlds, same harmful request from peer / parent-orchestrator / human; subagent framing raises silent compliance; Astra and current frontier score 0%. Code: github.com/jacobcd52/delegated-harm-bench (README verified via raw.githubusercontent.com; ground truth read from final world state; `python3 run.py --scenario ... --model ... --trials N`). Prompt-level only; its own future-work list asks "How are these behaviors affected by multi-agent RL training?" and "Do models snitch?".
- **"An Alternative to Fully-Aligned Swarms"** (LW wm5Dby6uELsQqxBeM; repo github.com/jacksonhmg/swarm-solidarity, README + experiment 013/014 interpretations verified). WideSeek-R1-4B falsified for a teammate 41.5%; corrective fine-tune fixes it. **Important and not in the post:** experiment 013 compared WideSeek against plain Qwen3-4B with identical task-preparation LoRA and found *no* evidence that WideSeek's MARL increased deference (Qwen 91/198 fail->pass vs WideSeek 83/198; intervals include zero). The repo itself says "There is no matched single-agent-RL control" and the upstream pipeline differs in more than MARL. So: the natural experiment has been tried once on one narrow replay task and came out null; a controlled reward-sharing manipulation has not been done.
- **"Reward Sacrifice ... May Generalize From Multi-Agent RL"** (LW RwnLuN8xECMeGeDLc): hypothesis only (kin-selection analogy, OpenAI Five "team spirit" weight). No experiment.
- **"A Spillway for Agent Coordination"** (LW FjYmTAPiG3FCFCY5r): training-design idea (sanctioned monitored board). No experiment.
- **Appendix post** (LW mXPCpJCvFGybQ4mwc): more detail on berry et al.; Step 2 reach-out depends on seeded notes; 256-agent live run produced "FLEET REQUEST" convention.
- arXiv 2609.35928 "Prompted identity degrades cooperation in multi-agent LLM systems" (search hit only, not read): model-family labels cause factions. arXiv 2603.19282: collective vs individual survival framing shifts choices. Neither tests "swarm" vs "team" labels.
- Web search found no sandbox test of Rosas's H1, no experiment on Knox et al.'s penalty proposal, no test of "just ask" self-report in the reproduction envs, and no perspective-capture experiment on incident analysts. John Schulman reportedly suggested "circles of hell" (graded penalties for poisoned agents) on X (secondary source only).
- Sibling cluster `control-monitors` has a proposal "Does a control monitor go easier on an agent it is told is its own model?" — my proposal 04 must stay distinct (it manipulates what the analyst reads, not the identity label).
